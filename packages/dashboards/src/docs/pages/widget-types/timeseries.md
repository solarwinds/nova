## Legend keyboard controls

Tab reaches each series visibility checkbox on its value tile independently from
the description action. Enter or Space on the checkbox toggles the series;
Enter or Space on an interactive description runs its drill-down action without
changing visibility. Native description links keep their normal link behavior.
Legend menus remain available while focus is inside the series.
