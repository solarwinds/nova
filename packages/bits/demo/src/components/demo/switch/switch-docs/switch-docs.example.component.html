<nui-switch> is a simple toggle control that can be associated with a binary value. Use the value input to control the value.

Required Modules

  • NuiSwitchModule

Basic Usage

Value Change Callback

For subscribing to value-change events, use the valueChange callback

Disabled Switch

Use the disabled input to enable/disable the switch

Accessible Name

A switch gets its accessible name from projected label content. For a switch without projected content, provide the ariaLabel input. If no label is provided, the component uses a localized fallback name. 

<nui-switch ariaLabel="Enable notifications" i18n-ariaLabel></nui-switch>
